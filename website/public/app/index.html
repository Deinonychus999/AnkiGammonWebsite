Anki connection settings

  • Anki is open on this computer.
  • AnkiConnect is installed: in Anki, Tools → Add-ons → Get Add-ons, code 2055492159, then restart Anki.
  • If the browser asked whether this site may reach apps on your device, you allowed it. If you dismissed it, allow it in the site settings next to the address bar.
  • If Anki asked whether to give this site access, you answered Yes. To fix a No, open Tools → Add-ons → AnkiConnect → Config in Anki, add to webCorsOriginList, and remove it from ignoreOriginList.
  • Safari and iPhone or iPad browsers can't connect to Anki. Use Download .apkg instead.
  • Using a different port for AnkiConnect? Change the address under Anki connection settings.
  • Enter the key under Anki connection settings, then send again.
  • Check that Anki isn't busy with a dialog, then send again. Cards already sent stay in Anki and are updated, not duplicated.

Browser or desktop?

Both make the same cards. The browser version needs no install and works on a phone or tablet, but it has no analysis engine, so it only takes positions eXtreme Gammon has already analyzed.

Getting analysis out of eXtreme Gammon

  • A whole match: analyze it in XG, save it, and drop the .xg file above. Pick the error thresholds and which player's mistakes to keep.
  • One position: save it as an .xgp file, or analyze it, press Ctrl+C in XG and paste the text above.
  • Comments you typed in XG come along and appear on the back of the card.

Frequently asked questions

Is my file uploaded anywhere?

No. The page downloads Python and AnkiGammon into your browser once, then reads your file and builds the deck on your device.

Why can't it analyze a position ID?

Analysis needs an engine such as GNU Backgammon, and neither it nor eXtreme Gammon runs in a browser. The desktop app runs GNU Backgammon for you.

Are these the same cards as the desktop app makes?

Yes. The browser runs the same AnkiGammon code as the desktop app, so the cards look and work the same.

How does Send to Anki work?

With Anki and the AnkiConnect add-on running, the page sends the cards to Anki on your computer. The first time, Anki asks whether to allow this site, and Chrome, Edge or Firefox may ask whether the site can reach apps on your device; say yes to both. Allowing the site lets it change your Anki collection, which is why Anki asks. Safari and iPhone or iPad browsers block this, so use Download .apkg there.

Why does the first visit take a few seconds?

The page downloads about 7 MB: Python compiled for the browser, plus AnkiGammon. Your browser keeps it, so later visits start faster.
